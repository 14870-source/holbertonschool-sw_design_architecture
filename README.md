# holbertonschool-sw_design_architecture

This repository contains projects and exercises focused on software design and architecture.

The projects introduce UML modeling concepts, including:

- Class diagrams
- Sequence diagrams
- System structure and relationships
- Object interactions

## Projects

### UML Introduction
